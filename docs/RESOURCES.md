## How to use a resource

1. Read or watch one focused lesson.
2. Recreate the example without copying line for line.
3. Change the data or requirements and test an edge case.
4. Save an artifact in your own repository.
5. Write a short note explaining the concept, trade-offs and anything still unclear.

**Link/access note:** vendor pages, cloud free tiers, exam objectives, prices, software access and documentation paths can change. Check the current official page before creating a paid account, booking an exam, or spending substantial time on a legacy stack.
