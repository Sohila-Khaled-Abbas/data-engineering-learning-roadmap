## Merged PDF status

The combined PDF is **not yet included**. Automated downloads of both source endpoints failed in the current environment, so there are no verified source binaries to merge. No substitute files have been presented as the merged document.

To complete the merge, download both files from the links above in your browser and upload the two original PDFs to the working chat. The merged output can then be checked and added here under a stable filename such as `learning-materials-bundle.pdf`.

## Study workflow

1. Read the relevant section of [the step-by-step roadmap](../ROADMAP.md).
2. Keep the PDF open beside the linked videos and exercises.
3. Capture your own notes, lab outputs, diagrams, and project evidence in this repository.
4. Treat course PDFs as source material; prefer current official documentation for version-specific software instructions.
