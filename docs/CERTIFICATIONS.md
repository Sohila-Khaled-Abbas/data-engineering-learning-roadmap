# Certification Planning

Certifications are optional checkpoints. Build practical evidence before paying for an exam, and verify the current exam page, objectives, price, availability and platform version first.

| Area | Official page / guide | When to consider it |
|---|---|---|
| AWS data engineering | [AWS Certified Data Engineer — Associate](https://aws.amazon.com/certification/certified-data-engineer-associate/) | After cloud fundamentals and a working pipeline |
| Databricks data engineering | [Databricks certification](https://www.databricks.com/learn/certification/data-engineer-associate) | After Spark/SQL and lakehouse practice |
| Power BI analytics | [PL-300 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/pl-300) | After a complete and reconciled Power BI report |
| Fabric analytics engineering | [DP-600 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/dp-600) | After semantic modeling, DAX, governance and optimization |
| Fabric data engineering | [DP-700 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/dp-700) | After ingestion, transformation, orchestration and monitoring practice |
| Azure data fundamentals | [DP-900 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/dp-900) | Early, if a fundamentals credential benefits your target role |
| DataStage / enterprise ETL | [IBM DataStage documentation](https://www.ibm.com/docs/en/iis/11.7.0) | Only if the exact credential and access are confirmed for your target role |
| Azure Databricks data engineering | [Microsoft credential resources](https://learn.microsoft.com/en-us/credentials/) | Verify that the exact credential/exam is available before planning around it |

Some credentials change names, exam codes, skills measured, or availability over time. This list is a starting point, not a promise that every exam is currently bookable. Do not pursue multiple overlapping certifications before finishing practical projects.
